**How to use this template.** Copy this file, rename it (for example `content/work/a-kinetic-window.md`), set `status: "published"` once it is approved, and replace everything below.

**The brief:** one sentence on what was asked for.

**The idea:** the move that made the project work.

**The difficult part:** one honest sentence about what had to be solved.

**What it became:** how people used it, or what it did for the brand.

Only name clients or show images that the studio has permission to publish.
